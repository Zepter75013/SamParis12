L'espace adhérent peut te prévenir quand il se passe quelque chose pour toi : un **message reçu** dans la messagerie, une **nouvelle course** au calendrier du club, le **rappel la veille** d'une course à laquelle tu es inscrit, ou un **nouveau document** dans « Plans & Documents ».

Deux façons d'être prévenu :

- **La notification** (push) s'affiche tout de suite sur ton téléphone ou ton ordinateur, **même quand le site est fermé**. Un clic dessus t'amène directement au bon endroit (la discussion, les courses, les documents).
- **L'e-mail** ne part que si tu **n'as pas vu l'élément dans l'heure**. Si tu as lu le message ou ouvert la page entre-temps, tu ne reçois rien : pas de boîte mail encombrée. Plusieurs nouveautés sont regroupées dans un seul e-mail.

## Activer les notifications sur ton appareil

:::etapes
1. Ouvre **Tes informations** (clique sur ton nom en haut à droite).
2. Dans le bloc **Notifications**, clique sur **Activer**.
3. Ton navigateur te demande l'autorisation d'afficher des notifications : réponds **Autoriser**.
4. Clique sur **Tester** : une notification d'essai doit apparaître.
:::

À faire **sur chaque appareil** où tu veux être prévenu (ton téléphone, ton ordinateur…). **Désactiver** arrête les notifications sur cet appareil seulement.

:::important Sur iPhone et iPad
Apple n'autorise les notifications que si le site est **installé sur l'écran d'accueil** (iOS 16.4 ou plus récent) :
1. ouvre le site dans **Safari** ;
2. touche le bouton **Partager** (carré avec une flèche), puis **Sur l'écran d'accueil** ;
3. ouvre l'espace adhérent **depuis cette nouvelle icône**, puis active les notifications comme ci-dessus.
:::

## Choisir ce que tu reçois

Le tableau du bloc **Notifications** te permet de choisir, pour chaque type (messages, courses, documents), si tu veux une **notification**, un **e-mail**, les deux ou rien. Tes choix sont enregistrés aussitôt et valent pour tous tes appareils.

Par défaut, les **e-mails sont activés** pour tout. Les notifications, elles, ne fonctionnent qu'une fois activées sur un appareil.

Chaque e-mail contient aussi un lien **mes notifications** qui t'amène directement à ce réglage.

:::faq Je ne reçois aucune notification
Vérifie dans **Tes informations** que l'appareil indique « Activées », puis clique sur **Tester**. Si rien n'apparaît : les notifications sont peut-être bloquées dans les réglages de ton navigateur ou de ton téléphone (mode « Ne pas déranger », notifications du navigateur désactivées). Désactive puis réactive les notifications dans le bloc **Notifications**.
:::

:::faq Je reçois une notification alors que j'ai déjà lu le message
La notification part à l'instant où le message est envoyé ; si tu étais déjà sur la discussion, ignore-la simplement. L'**e-mail**, lui, ne part jamais pour un message que tu as lu.
:::
