**Plans & Documents** regroupe les documents du club à télécharger. Il y a **quatre emplacements** fixes :

- **Programme trimestriel** : les plans d'entraînement running ;
- **Résultats** : par exemple le résultat du test VMA ;
- **Grille d'allures piste** : les allures de fractionné et de VMA par niveau ;
- **Plan des lieux** : le plan du stade.

Chaque emplacement contient **un seul document à la fois**.

## Télécharger un document

Chaque carte affiche le **titre**, l'**auteur**, la date d'ajout et le nom de la personne qui l'a déposé. Clique sur **Télécharger ↓** pour récupérer le fichier PDF.

Tu retrouves aussi l'écran dans le menu de ton profil (**Tes documents**).

## Ajouter ou remplacer un document

Cette partie est réservée aux adhérents dont le rôle comprend **Ajouter des documents**.

:::etapes
1. Sur la carte de l'emplacement voulu, clique sur **Ajouter le document** (ou **Remplacer le document** s'il en existe déjà un).
2. Renseigne le **Titre** et l'**Auteur**.
3. Choisis le **fichier PDF** (20 Mo au maximum).
4. Clique sur **Enregistrer**.
:::

:::attention
Un nouveau document **remplace** le précédent de cet emplacement : l'ancien n'est plus proposé au téléchargement. Seuls les fichiers **PDF** sont acceptés.
:::
