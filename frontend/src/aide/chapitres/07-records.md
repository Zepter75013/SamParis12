**Records du Club** présente les meilleures performances des adhérents du SAM Paris 12. Les classements sont **calculés automatiquement** à partir des résultats chronométrés saisis dans [Résultats](aide:resultats) : tu n'as rien à saisir ici.

## Les vues

Les boutons du haut changent la présentation :

- **Féminin** et **Masculin** : les meilleurs temps par épreuve, pour chaque genre ;
- **Par type de course** : le meilleur de chaque type (10 km route, semi-marathon, marathon, trail…) ;
- **Par catégorie** : le meilleur de chaque catégorie d'âge ;
- **Hit-parade** : les 20 meilleures performances classées par allure, toutes épreuves confondues ;
- **Autres records** : rubrique prévue pour d'autres types de records ; elle est vide pour le moment.

Clique sur le nom d'un adhérent pour ouvrir la fiche de ses courses.

## Exporter vers Excel

Le bouton **Télécharger Excel** enregistre sur ton appareil le tableau de la vue affichée.

:::info
Si le tableau est vide, c'est qu'aucun résultat chronométré n'est encore enregistré : les records apparaîtront dès que des résultats seront saisis.
:::
